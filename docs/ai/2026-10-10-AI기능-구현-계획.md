## 1. 코드 조사 요약 — 계획이 기대는 사실들

### 1-1. 날짜/시간 모델 (`lib/src/domain/todo.dart`)

| 모드 (`Todo.dateMode`) | 필드 조합 |
|---|---|
| none | `dueAt == null` |
| allDay | `dueAt = DateTime(y,m,d)` **로컬 자정**, `isAllDay=true`, `endAt=null` |
| startTime | `dueAt = 로컬 날짜+시각`, `isAllDay=false`, `timeAnchor='start'` |
| endTime | 위와 같고 `timeAnchor='end'` (마감 시각) |
| range | `dueAt`(시작) + `endAt`(종료), `isAllDay` 로 양끝 시간 표시 여부 |

- `dueAt` 은 **instant** 다. 시트는 로컬 `DateTime` 을 만든다 (`add_todo_sheet.dart:389-427 _serializeDate`).
- UTC 변환은 **Supabase 경계에서만** 한다 (`supabase_todos_api.dart:63-67` `toUtc().toIso8601String()`). 원격에서 읽은 값은 UTC (`:162`). 그래서 날짜를 꺼낼 때는 **항상 `toLocal()` 먼저** (`add_todo_sheet.dart:279-282` 주석: UTC 그대로 읽으면 한국 종일 항목이 전날이 된다).
- 로컬 DB 실측: `due_at` 이 `...T00:00:00.000Z` 와 `...T00:00:00.000 +09:00` 두 형태로 섞여 있다. 같은 instant 비교는 `isAtSameMomentAs` 로 해야 한다 (`add_todo_sheet.dart:463-466`).
- **함정**: 종일 항목(KST 자정)을 UTC ISO 로 AI 에 보내면 `전날 15:00Z` 가 된다. 아이디어 문서의 "시각은 UTC ISO 로" 는 **AI 입출력에는 적용하지 않는다**(§2-5 날짜 규칙).

### 2-4. 입력 직렬화 `ai_todo_payload.dart`

```json
{"n":3,"t":"제목","c":"회사 할일","k":"task","s":"undone","d":"2026-10-12","age":41,"kids":2,"p":1,"desc":"앞 300자"}
```
- `n`: 1부터 붙인 번호. 화면이 `Map<int, String> nToId` 를 들고 있다가 응답을 역매핑.
- `c`: 카테고리 **이름**(id 아님). `s`: `undone|doing|done`. `k`: `task|note`.
- `d`: §2-5 의 로컬 문자열. 없으면 키 생략. `p`: 부모의 `n`(T5 만). `kids`: 하위 수(T3).
- `desc`: `aiSendDescriptionProvider == true` 일 때만, 앞 300자. 단, **T1·T4 처럼 대표님이 항목 하나를 눌러 부르는 기능은 그 항목 설명을 항상 보낸다**(설정 안내 문구에 명시).
- 제외: `isSeriesMaster`, 보관 카테고리(`archivedCategoryIdsProvider`).
- 정렬: 화면 순서를 그대로 쓰되 **updatedAt 을 정렬 키로 쓰지 않는다**(sortOrder → createdAt desc → id).

### 2-5. 날짜 규칙 (T2·T3·T4·T5 공통)

- **AI 로 보낼 때**: `final l = dueAt.toLocal();` → 종일이면 `"YYYY-MM-DD"`, 시각이 있으면 `"YYYY-MM-DD HH:mm"`, 기간이면 `"시작~끝"`. 입력 머리에 `"today":"2026-10-10(토)","tz":"Asia/Seoul"` 를 같이 보낸다. **UTC ISO 금지.**
- **AI 에게 받을 때**: `date:"YYYY-MM-DD"`, `time:"HH:mm"|null` 로만 받는다. 앱이 `DateTime(y,m,d)` (종일, `isAllDay:true`) 또는 `DateTime(y,m,d,h,mi)` (`isAllDay:false`, `timeAnchor:'start'`, 마감 표현이면 `'end'`) 로 **로컬 시각**을 만든다. 시트의 `_serializeDate` 와 같은 모양이다. `DateTime.parse(ai문자열)` 금지.
- 검증: 정규식 → `DateTime(y,m,d)` 를 만든 뒤 y/m/d 가 그대로인지(2/30 → 3/2 정규화 차단), 시각 0~23/0~59, 범위 `오늘-7일 ~ 오늘+400일`. 하나라도 어긋나면 **날짜만 버리고 항목은 살린다.**
- 기간(endAt)은 AI 경로에서 만들지 않는다(MVP).
- UTC 변환은 기존 Supabase 경계(`supabase_todos_api.dart:67`)가 한다. AI 코드는 신경 쓰지 않는다.

**함정**: 플랜 한도를 가장 많이 쓰는 기능 — Enter 로만 보내고 입력 중 자동 호출 금지. `?` 로 검색하던 기존 사용(사실상 없음)을 깨지 않게 not ready 면 기존 검색.

## 5. 구현 순서 (커밋 단위)

메시지는 저장소 관례(`feat(scope): 한국어 요약`)를 따른다. 각 커밋은 AGENTS.md 검증 3종 통과가 조건.
